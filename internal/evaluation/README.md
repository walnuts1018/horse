# オフライン評価

`mise run evaluation:run`は、保存済み抽出結果を正解データと照合し、JSON形式の指標を出力します。評価データセットを切り替える場合は`EVALUATION_DATASET`にファイルパスを設定します。Gemini APIは呼び出しません。

データセットにはバージョンと一意なケースIDを付け、原本画像を含めず、正解値と実行済みの抽出結果を保存します。実データを評価に使う場合は、利用者の同意とアクセス制御を確認し、公開リポジトリには追加しないでください。

品目検出は印字品名を正規化して照合し、明細金額と商品名の一致率、`Verify`の税額整合、IoU 0.5以上の画像領域一致、重複明細の個数、修正操作数を集計します。正規化は空白・句読点・記号を除去した完全一致です。

費用は`priceEstimateStatus`が`estimated_paid`または`free_tier`の実行だけを合算し、価格付き実行1件当たりの平均も出力します。金額は推定費用であり、請求実績ではありません。価格不明や為替レート未設定などの実行は`unpricedRuns`に計上します。

同梱データセットは人工的な例です。実際の日本語レシートに対する精度を示すものではありません。
