# AI抽出の監査とオフライン評価

各抽出実行はモデル、ルート、思考レベル、サービス階層、プロンプト版、価格表版、入出力token数、為替レートと出典、価格計算日時、推定費用を記録します。推定費用は`estimated_paid`と`free_tier`を区別し、価格表にないモデルや為替レートがない実行はゼロ円とみなさず、それぞれ`unknown_model_price`または`missing_exchange_rate`として残します。失敗した呼び出しは`unavailable_failed_run`です。推定額は実際の請求額ではありません。

評価データセットは版とケースIDを持つJSONです。各ケースには人手で確認した正解値、保存済みの抽出結果、抽出実行の価格metadata、任意の人手修正操作数を含めます。原本画像は含めず、利用者の実データを公開データセットへ追加しません。

`mise run evaluation:run`は同梱の人工データを使い、Geminiを呼び出さずに評価します。別のデータセットは`EVALUATION_DATASET=/path/to/dataset.json mise run evaluation:run`で指定します。

出力には品目検出のprecision/recall、印字金額の完全一致率、税額整合率、商品名正規化の一致率、証拠領域のIoU 0.5以上のprecision、同じ印字名と金額の重複明細precision、人手修正操作数、価格を判定できた実行数と推定費用を含めます。品目照合は印字名の空白・句読点・記号を取り除いた完全一致です。税額整合は実際の処理と同じ`Verify`で判定します。

同梱データは評価基盤の動作例に限られ、日本語の実レシートに対する精度や実利用時の費用を示しません。実データで精度を評価する前に、利用者の同意、保管場所、アクセス制御、削除期限を決め、非公開の評価環境を使います。
