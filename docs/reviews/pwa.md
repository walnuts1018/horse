# オフライン下書き

Service Workerはアプリの静的ファイルだけをCache Storageへ保存します。認証済みHTML、GraphQL、認証、イベント、文書、購入APIのレスポンスは保存しません。ネットワークに接続できないナビゲーションには、購入下書き用の静的shellを返します。

アプリはオンラインで`/auth/me`、世帯一覧、選択中の世帯を取得し、閲覧者がその世帯のメンバーであることを確認した後に、利用者IDと世帯IDだけを`localStorage`へ記録します。shellはURLの世帯IDとmarkerが一致した場合に限り、IndexedDBの`purchase-drafts-v3`から`[memberId, householdId]`と完全一致する未送信下書きを読み、編集結果を同じキーへ保存します。shellはオフライン中に認証/API/世帯情報を取得せず、markerがない、壊れている、または世帯IDが一致しない場合は下書きを表示しません。

オンラインlogoutはremote logout要求の前にmarkerを削除します。offline shellの「この端末で下書きを隠す」操作もmarkerだけを削除し、IndexedDBの下書きは削除しません。オフライン中はremote logoutを実行できないため、サーバー側のsessionは有効なままです。オンラインへ戻った後、cookieがまだ有効で`/auth/me`と世帯の確認に成功するとmarkerが再作成されます。

このmarkerはscopeの誤選択を防ぐための情報であり、認証情報や暗号鍵ではありません。同じブラウザープロファイルへ物理アクセスできる人は、開発者ツールなどからmarkerとIndexedDBを読み書きできます。ブラウザーの境界では共有端末上の利用者を隔離できないため、共有端末ではOSのユーザープロファイルを分けるか端末ロックを使用してください。オフライン中にsessionの失効や世帯メンバー資格の変更を確認することもできません。
