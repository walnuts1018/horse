# 機能・運用の未解決項目

## 1. 実装上の不足

| 優先度 | 項目 | 現状と必要な対応 |
| --- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| P1 | メールの自動取り込み | 購入メールをHorse専用アドレスへ転送する方式を採用しました。転送先の発行、IMAPS受信、原本・添付・job登録のコードは実装済みですが、Stalwartのメールボックス設定は保留しています。Infraから未設定のExternalSecretとIMAPS環境変数を削除したため、メール受信は無効で、実IMAPS受信は未検証です。 |
| P2 | 定期支出の実績管理 | 定期支出の登録と月額換算はありますが、支払期日の到来、購入実績との照合、未払いの表示、次回予定日の更新を連携する仕組みは見当たりません。定期支出を本格的に管理するなら追加する価値があります。 |
| P2 | 保存済み原本の管理 | アップロード前のファイル削除はできますが、保存済み原本の削除・保存期限管理・関連する購入との整合的な削除は確認できません。取り込みを長期運用するなら必要です。 |

## 2. 運用設定

Infra mainでは500円のSpend Capを前提に通常WorkerのGemini処理を有効にしました。実環境で`GEMINI_ENABLED=true`かつWorkerがReadyであることを確認しました。キューは空で、合成原本の処理は未確認です。Stalwartメールボックス設定の保留に伴って未設定のExternalSecretとIMAPS環境変数を削除し、Argo CDはHealthyになりました。

## 3. 推奨する作業順序

メール自動取り込みはStalwartのメールボックス設定を再開した後に実環境で確認してください。残る明細取引の照合と保存済み原本の管理は、それぞれの要件に沿って実装してください。
