# 機能・運用の未解決項目

## 1. 実装上の不足

| 優先度 | 項目 | 現状と必要な対応 |
| --- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| P1 | メールの自動取り込み | 購入メールをHorse専用アドレスへ転送する方式を採用しました。転送先の発行、IMAPS受信、原本・添付・job登録のコードは実装済みですが、Stalwartのメールボックス設定は保留しています。Infraから未設定のExternalSecretとIMAPS環境変数を削除したため、メール受信は無効です。 |
| P2 | 保存済み原本の保持期間 | 保存済み原本は、未確認かつ抽出完了済みで、証拠や添付に使われていない場合に削除できます。保存期限に基づく自動削除は未実装です。確認済み購入の証拠を保持する期間と削除後の監査要件を決めてから、自動cleanupを実装してください。 |

## 2. 運用設定

Infra mainでは500円のSpend Capを前提に通常WorkerのGemini処理を有効にしました。実環境で`GEMINI_ENABLED=true`かつWorkerがReadyであることを確認しました。Stalwartメールボックス設定の保留に伴って未設定のExternalSecretとIMAPS環境変数を削除し、Argo CDはHealthyになりました。

## 3. 推奨する作業順序

保存済み原本の保持期間は、証拠の保持と削除後の監査要件を決めてから実装してください。
