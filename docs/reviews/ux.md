# Horse UXレビューの未確認項目

現行コードで実装済みの改善はレビュー残件から除き、ブラウザーや実機での確認が必要な操作を記録します。

## P1：日常利用と記録の正確性

### 資金記録の再送

設定画面の入金・口座移動は、送信内容と冪等キーを家庭単位で保存し、タイムアウトや再読み込み後に同じ入力を再送します。通信成功後に再試行情報を消します。公開環境で通信失敗・再読み込み・再試行を行い、記録が1件だけ作られることを確認します。

### スマートフォンでの連続入力

購入画面は品名・金額のEnter移動、IME変換中のEnter抑止、保存前の下書き復元に対応しています。ソフトウェアキーボードを開いたまま連続入力し、IME確定・画面スクロール・保存・再表示まで完了できるかをAndroid ChromeとiOS Safariで確認します。

### カメラ撮影から取り込みまで

取り込み画面には撮影ボタンとファイル選択ボタンがあり、撮影後に画像確認、回転、範囲切り抜き、追加を行う画面も実装されています。実機カメラの起動、撮影画像の向き、切り抜き、アップロード、解析結果の確認までをAndroid ChromeとiOS Safariで通して確認します。

### モバイルでの文字と操作領域

幅760px以下では入力文字を16px、補足文字を12px、密なラベルを10pxにし、主要ボタンと選択欄の高さを44px以上にする指定があります。320px、375px、430px程度の画面で購入・取り込み・精算を操作し、文字の判読性、タップ範囲、横スクロールの有無を確認します。

## P2：入力と移動の一貫性

### 入力画面の順序とナビゲーション

品目の追加、負担割合の変更、購入の確定までをスマートフォンとPCで操作し、日常的な登録に不要な画面移動やスクロールが残っていないか確認します。キーボードだけでの商品検索、品目追加、負担割合変更、確定も確認します。

## P3：支援技術とブラウザー操作

撮影ダイアログのフォーカス移動、Tab移動の制限、Escape終了、ラベルの読み上げをキーボードとスクリーンリーダーで確認します。モバイルドロワー表示中は背景ページを固定し、スクロール境界でのoverscrollを抑止しています。AndroidとiOSの実機で、ドロワーの開閉・スクロール中にページが意図せず更新されないことを確認します。

未保存変更時はアプリ内遷移とブラウザー離脱に確認を表示し、購入画面は保存済み下書きを再読み込み後に復元します。画面遷移はファイルベースのルートとURL履歴で管理します。公開環境で未保存入力中の遷移・再読み込み、URLの戻る・進む・直接再読み込みが期待どおり動くことは未確認です。フロントエンドにはPlaywrightなどのブラウザーE2Eテストがなく、ネットワーク復旧後の購入再送、入金・送金の再送、複数幅のモバイル操作、キーボードのみの購入入力を回帰確認できる構成も未整備です。
